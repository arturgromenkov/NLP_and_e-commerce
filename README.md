# 🧾 Receipt Recognition Service

Добро пожаловать в репозиторий проекта! Здесь мы собираем решение для распознавания чеков: от приёма изображения до выдачи структурированного ответа и удобного веб-интерфейса.

## 🎯 О проекте

Проект представляет собой связку из двух независимых компонентов, которые работают в тандеме:

- **Сервис распознавания** — принимает чек на вход, возвращает структурированный ответ в формате JSON.
- **Веб-интерфейс** — аккуратный и минималистичный UI в фирменном стиле **М.Видео**, который отправляет запросы к сервису и отображает результат.

## 📁 Структура репозитория

```
.
├── PriceDadata-service/        # Сервис распознавания чеков (backend)
├── Mvideo-interface/             # Веб-интерфейс в стиле М.Видео (frontend)
└── notebooks/      # Песочница для экспериментов
```

### 🔧 `PriceDadata-service/`
Сервис, который:
- принимает на вход чек,
- обрабатывает его,
- возвращает результат в формате **JSON**.

### 🎨 `Mvideo-interface/`
Простой, но приятный глазу интерфейс, оформленный в стилистике **М.Видео**. Отправляет запросы к сервису и наглядно показывает результат пользователю.

### 📓 `notebooks/`
Свободная зона для исследований. Сюда можно класть:
- Jupyter-ноутбуки,
- эксперименты и прототипы,
- вспомогательные материалы.

Можно создавать подпапки под свои задачи — структура не ограничена.
